# carve-css

CSS for HTML produced by Carve 0.1 engines. Its styles are scoped to the `.carve` container. See the [Carve documentation](https://markup-carve.github.io/carve/).

## Install

```sh
npm install @markup-carve/carve-css
```

## Usage

```css
@import "@markup-carve/carve-css";
```
